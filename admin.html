Publishing

Set this up once and every editor tab gets a Publish to live site button that commits straight to the repo — no downloading, no re-uploading.

Connection

Recommended: leave this on Netlify function. The GitHub token then lives in Netlify's environment variables (GITHUB_TOKEN, GITHUB_REPO, ADMIN_SECRET) and never touches this browser. Use GitHub token in this browser only if you can't add the function — the token is then stored in this browser's local storage, on this device.
Fine-grained PAT, this repo only, Contents: read & write. Nothing else.

One-time setup (Netlify function)

1. Commit netlify/functions/commit.js and netlify.toml to the repo this admin site deploys from.
2. In Netlify → Site configuration → Environment variables, add GITHUB_TOKEN (fine-grained PAT, Contents: read & write), GITHUB_REPO (owner/name), GITHUB_BRANCH (usually main) and ADMIN_SECRET (any passphrase you choose).
3. Redeploy, put the same passphrase in the box above, hit Test connection.
